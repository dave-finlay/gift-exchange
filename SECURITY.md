# Security

If you find a security problem, please report it privately through
GitHub's [private vulnerability reporting](https://github.com/dave-finlay/gift-exchange/security/advisories/new)
rather than in a public issue.

This is a small personal project, so there's no bug bounty and no
guaranteed response time, but reports are welcome and will be taken
seriously.

If you run your own copy, keep it up to date: security fixes go into
`main`, and the dependencies are updated regularly.
