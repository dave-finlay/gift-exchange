# VEX documents from autosec

This branch is written by autosec. Each release's OpenVEX document is in
`releases/<version>/vex.openvex.json`, with its basis record beside it
(`basis.sigstore.json`): what the document rests on, signed by autosec.
How to check one:
https://github.com/dave-finlay/autosec-public/blob/main/basis/v1.md
